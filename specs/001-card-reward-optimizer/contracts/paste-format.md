# Contract: 貼上的彙整結果格式（公開版）

依 FR-001、FR-025、FR-039、FR-040；T019 決定（2026-11-03）。

**使用者決定**：
- 格式為 JSON；由網站提供穩定且完整顯示的版本化 prompt，讓使用者的 LLM 產出符合下列欄位的 JSON（理由：請使用者自行撰寫 JSON 有使用門檻）。
- 各通路金額給**涵蓋期間總額**，月均由程式計算（FR-013）。
- **不請 LLM 填回饋率**；回饋率由已發布的公開資料（RewardRule）查詢。

**以下欄位的名稱、編碼細節為草稿**：`[INFERRED: 欄位名稱與型別由助理依 data-model.md 擬定，待使用者確認]`

## 結構

```json
{
  "formatVersion": "<與 prompt 版本對應>",
  "period": { "start": "YYYY-MM", "end": "YYYY-MM" },
  "currency": "TWD",
  "cards": [ { "issuer": "<國泰|永豐|富邦|台新>", "name": "<卡名>" } ],
  "channels": [ { "name": "<通路名稱>", "total": 0, "mainCard": "<cards 中的卡名>" } ],
  "largeItems": [ { "category": "<類別>", "amount": 0 } ]
}
```

## 欄位規則

| 欄位 | 規則 |
|---|---|
| formatVersion | 必須是系統支援的版本；不支援則拒絕並提示使用最新 prompt |
| period | start 不晚於 end；涵蓋不足三個月時提示但允許繼續（FR-002） |
| currency | 只能是 `TWD`；其他幣別拒絕 |
| cards | 發卡行限國泰、永豐、富邦、台新（FR-020）；**不得含卡號、末四碼、CVV、姓名** |
| channels[].name | 對應使用者定義的通路；無法歸類者歸入「無腦刷」（FR-004） |
| channels[].total | 整數新台幣，不得為負；無消費為 0 |
| channels[].mainCard | 必須對應 cards 中的一張卡 |
| largeItems[].amount | 整數新台幣，**須達使用者所設門檻**（預設 10,000 元，單筆判定），由程式驗證（FR-040） |
| 其他欄位 | 預設拒絕：出現未定義的欄位一律拒絕 |

不含：逐筆明細、商家、回饋率。回饋率由程式依 mainCard 與通路查 RewardRule（FR-005）；查無資料則標示未知。

欄位數量與字串長度上限：`[TBD: 尚未定義]`。

## 邊界情況處理（`[INFERRED: 使用者授權助理決定，待使用者確認]`）

1. **重複貼上**：涵蓋期間與既有快照重疊時，顯示提示並要求使用者選擇「取代既有快照」「另存為新快照」或「取消」；系統不自動合併，避免重複計入。
2. **退款與分期**：由 prompt 要求 LLM 在各通路以淨額計入，分期以該期間實際入帳金額計；格式中不另設欄位。淨額為負者拒絕並請使用者檢查。
3. **預覽修正**：預覽畫面可逐欄編輯；編輯後重新套用同一份驗證規則才能確認。

## 稽核對應

- SC-001：格式錯誤、欄位缺漏、數值超出範圍、非新台幣、含卡號或 CVV、含可疑內容的測試集須 100% 被拒絕；通過者的各通路月均須與貼上總額除以月數一致。
- 規則實作於 `rules/`，由兩個執行器共用（見 validator-contract.md）。
